================================================================================
  Lab05  Part-2 : CSMA/CA Efficiency and Fairness   (uses nsta-udp.cc)
================================================================================

Under high load, CSMA/CA does not perform well. You will observe this by running
5 network instances with 1, 5, 10, 20 and 30 client nodes, and use summarize.py
to compute two metrics per instance:

  "Avg. Throughput"    = average of the per-second TOTAL throughputs
  "Avg. Min/Max ratio" = average of the per-second (min/max) throughput ratios

Run each instance and summarise (each run writes csma-ca-nsta-udp-<N>.txt):
     ./ns3 run "nsta-udp --uplinks=1"   && python3 summarize.py csma-ca-nsta-udp-1.txt
     ./ns3 run "nsta-udp --uplinks=5"   && python3 summarize.py csma-ca-nsta-udp-5.txt
     ./ns3 run "nsta-udp --uplinks=10"  && python3 summarize.py csma-ca-nsta-udp-10.txt
     ./ns3 run "nsta-udp --uplinks=20"  && python3 summarize.py csma-ca-nsta-udp-20.txt
     ./ns3 run "nsta-udp --uplinks=30"  && python3 summarize.py csma-ca-nsta-udp-30.txt
(or run everything at once:  python3 summarize_automate.py --roll <ROLL_NO>)

NOTE: grading reads these csma-ca-nsta-udp-<N>.txt files from the ns-3 directory
to recompute the correct metrics, so keep them in place (run all 5 instances).
